# Pasta de Imagens (Assets)

Coloque aqui seus arquivos de imagem para o portfólio:

- `profile.jpg` ou `avatar.png`: Sua foto de perfil profissional.
  - Para usá-la, basta substituir o conteúdo dentro de `.avatar-wrapper` no arquivo `index.html`:
  ```html
  <div class="avatar-wrapper">
    <div class="avatar-img-placeholder">
      <img src="assets/images/profile.jpg" alt="Foto de Hugo Verissimo de Mello">
    </div>
  </div>
  ```
- `projetos/`: Imagens de prévia ou screenshots dos seus projetos.
